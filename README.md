# Meridian Passage — Passport Assistance Service

Static website built with HTML5, Tailwind CSS v4 (CLI) and Vanilla JavaScript. No framework, bundler or CDN.

## Commands

```bash
npm install
npm run dev     # inject partials + copy fonts + watch CSS
npm run build   # inject partials + copy fonts + minified production CSS
npm run pages   # re-inject partials only (after editing partials/*.html)
```

Open any `.html` file through a local static server (ES modules don't load over `file://`), e.g. `npx serve .`.

## Using the foundation

- **Colours:** prefer semantic utilities — `bg-bg`, `bg-surface`, `bg-surface-2`, `text-ink`, `text-ink-muted`, `border-line`, `bg-primary text-on-primary`, `bg-accent text-on-accent`. They switch automatically in dark mode. Brand scales (`navy-*`, `teal-*`, `gold-*`, `paper-*`) are for fixed accents.
- **Dark mode:** `<html data-theme="dark">`; use `dark:` for one-off overrides. Toggle with any `<button data-theme-toggle>`.
- **RTL:** `<html dir="rtl">`; toggle with `<button data-dir-toggle>`. Use logical utilities (`ms-*`, `pe-*`, `start-*`, `text-start`, `border-s`); add `.icon-flip` to arrows/chevrons.
- **Header/footer:** edit `partials/*.html`, then `npm run pages`. Hooks: `[data-nav-toggle]`, `[data-dropdown-toggle]`, `[data-theme-toggle]`, `[data-dir-toggle]`. Below 64rem the menu is full-screen and holds the toggles and CTAs.
- **Hero height (all public pages):** use `<section class="hero">` with a `.container-page` child. Height comes from `--hero-h` in `tokens.css` (40rem, 42rem from 80rem, 44rem from 96rem), never from `vh`, so every page's hero is identical. For art inside a hero use `.hero-fit` so it can't stretch the hero.
- **Section patterns:** `.section-head` (+ `.is-center`), `.cta-row` (centred on mobile), `.chip`, `.photo` (photo frame), `.link-arrow`, `.on-dark` (text on permanently navy bands). Home-only patterns are in `home.css`; behaviour in `src/js/home.js` via `data-tabs`, `data-filter`, `data-checklist`, `data-country-check`.
- **Imagery:** real photographs in `public/assets/photos/` (Pexels, free licence, no credit required; 50 distinct photos across all six content pages). Every section has at least one. Frames: `.photo`, `.arch`, `.clipboard`, `.svc-card`, with navy scrims (`.scrim-start`, `.scrim-bottom`, `.scrim-flat`, `.scrim-hero`) so text stays readable in both themes. No illustrations or vector artwork.
- **Contact form:** `src/js/contact.js` validates (required fields, email, phone, 20-character message, consent) and shows an error summary, a sending state and a success panel. It does not send anywhere until you set `FORM_ENDPOINT` at the top of that file (it then POSTs JSON). `?topic=` and `?country=` pre-fill the form.
- **Map:** `contact.html` embeds OpenStreetMap. The pin is set by `data-lat` / `data-lon` on `.map-frame`, the iframe `src` (`bbox` and `marker`) and the two links in the same section. **The shown address is fictional, so these coordinates are a placeholder (a road intersection in Northgate, Seattle); replace all four with your real office coordinates.**
- **Checklists:** `src/js/checklist.js` saves ticks per list in `localStorage`, plus Reset, Print and the country picker. Typical-document lists are examples only; every section says requirements vary by country and passport authority.
- **RTL text:** avoid the `text-start` utility in pages; use `ltr:text-left rtl:text-right` (see `base.css`).
- **Icons:** `<svg class="icon" aria-hidden="true"><use href="#i-name"/></svg>`; add symbols in `partials/sprite.html`. Use `.if-light` / `.if-dark` / `.if-ltr` / `.if-rtl` to show content for one state only.
- **Animation:** add `.reveal` (optionally `style="--reveal-delay:120ms"`). Respects `prefers-reduced-motion`; content stays visible without JS.
- **Layout:** `.container-page` (+ `.is-narrow` / `.is-wide`), `.section` (+ `.is-alt`, `.is-tight`), `.grid-auto` (set `--grid-min`).
